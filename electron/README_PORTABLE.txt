AcademicOS Portable (Windows)

1) Estrai lo ZIP in una cartella (es: Desktop\AcademicOS_Portable)
2) Avvia AcademicOS.exe
3) I dati vengono salvati nella cartella "data" accanto all'exe.
4) Per fare backup: Impostazioni -> Esporta DATI / Esporta IMPOSTAZIONI

Nota: Windows può mostrare un avviso SmartScreen perché l'app non è firmata (normale).
